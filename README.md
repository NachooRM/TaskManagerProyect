Task Manager App

📌 About the Project
This is a personal project developed to improve my programming skills and reinforce concepts learned during my university studies in Information Systems Engineering.

The main goal of this project is to build a fully functional application that allows users to manage their personal projects and tasks.

🎯 Objectives
- Practice backend development using Node.js and Express
- Work with relational databases using Sequelize and SQLite
- Apply concepts such as authentication, CRUD operations, and data relationships
- Strengthen my understanding of database design and normalization

⚙️ Features
- User registration and login (authentication)
- Create and manage personal projects
- Each project can contain multiple tasks
- Tasks can have different states (e.g., pending, in progress, completed)
- Basic frontend interface using HTML, CSS, and Bootstrap

🛠️ Technologies Used
- Node.js
- Express
- Sequelize (ORM)
- SQLite
- JavaScript (ES6+)
- HTML & CSS
- Bootstrap
